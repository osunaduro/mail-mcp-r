# Documentation

## Propósito

Este directorio contiene la documentación orientada a personas.

Su objetivo es facilitar la comprensión, operación, mantenimiento y evolución del proyecto sin necesidad de inspeccionar directamente el código fuente.

## Responsabilidad

La documentación contenida en este directorio constituye una representación humana del proyecto.

No es la fuente de verdad de la memoria operativa ni de la arquitectura.

La información autoritativa reside en:

- project.yml
- Memory Layer
- Knowledge Layer
- Decisiones persistidas

## Contenido esperado

Este directorio puede contener, entre otros:

- Manuales de usuario.
- Guías de desarrollo.
- Referencias de APIs.
- Guías de despliegue.
- Diagramas.
- Tutoriales.
- Documentación funcional.
- Documentación técnica.

## Mantenimiento

La documentación deberá mantenerse alineada con el estado real del proyecto.

El Documentation Specialist es el responsable principal de auditar, generar y mantener este contenido.

## Contrato

Todo proyecto MEKA debe disponer de un directorio `docs/`.

La organización interna es libre y dependerá de las necesidades del proyecto.
